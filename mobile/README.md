# SDR Watch — мобільний застосунок (Flutter, Android / iOS)

Підключення до модулів Raspberry Pi + SDR: живий спектр і водоспад з підказками, сигнали з класифікацією
й оцінкою відстані, живе FPV-відео, історія з флешки модуля, дистанційне керування, фонові сповіщення.

```bash
flutter pub get
flutter run                       # на підключеному телефоні
flutter build apk --release       # Android APK
flutter build ipa                 # iOS (Mac + Xcode)
flutter analyze
```

Структура `lib/`:
- `main.dart` — запуск, тема, ініціалізація сповіщень і фонового сервісу
- `models.dart` — модуль, сигнал, кадр спектра, подія; форматування й кольори класів
- `api.dart` — REST-клієнт з автоматичним вибором робочої адреси модуля
- `live.dart` — WebSocket: спектр, водоспад, сигнали, події, стан стеження
- `background.dart`, `notifications.dart` — фоновий моніторинг усіх модулів і сповіщення
- `screens/` — головний екран («камери»), додавання модуля (QR / LAN / вручну), екран модуля
  (Ефір, Сигнали, Відео, Історія, Керування), деталі сигналу, налаштування
- `widgets/` — спектр, водоспад, панель підказок, плитки сигналів
